## Live check R1, Linux: not run, the network too slow (2026-11-22)

Scripts: [`owl-624-linux.sh`](../live-checks/owl-624-linux.sh) and [`owl-627-linux.sh`](../live-checks/owl-627-linux.sh), Docker 29.4.0 on macOS, arm64, 18 CPUs. Before building either rig, the network was measured, 21:50Z to 22:52Z:

| Source | Through | Rate |
| --- | --- | --- |
| `ports.ubuntu.com`, `Packages.gz` of noble | the host's `curl`, 20 s | 31 kB/s |
| `repo1.maven.org`, `commons-lang3` 3.17.0 | the host's `curl`, 20 s | 25 kB/s |
| `static.rust-lang.org`, the stable channel file | the host's `curl`, 20 s | 15 kB/s |
| `go.dev`, the Go 1.27.4 Linux tarball | the host's `curl`, 60 s | 4 kB/s, 235 kB |
| `ports.ubuntu.com`, the same file | `wget` in a container, through Docker's proxy | 28 kB/s, 1.1 MB in 41 s |
| Docker Hub, `ubuntu:24.04` (about 29 MB compressed) | `docker pull` | not done after 60 minutes, stopped at 22:51Z |

The rigs download about 600 to 900 MB before their first gate: the distribution's packages (a JDK, PHP, Ruby, Python, about 150 MB), Go (75 MB), Gradle (130 MB), the .NET SDK (about 200 MB), a Rust tool chain and the crates of the build (about 200 MB), then what the gates fetch (about 120 MB). At 28 kB/s that is 6 to 9 hours, so the check was stopped and nothing was built. The run caches of both slices still rest on the macOS checks alone, which the rule allows.

## For whoever runs it

- **The rule on Linux.** A variable is kept when the gate is green with it set; on Linux the run with it removed is expected green too, because bwrap's private home takes the install and loses it with the command (OWL-617 R1). That green run is recorded, not a reason to remove the variable: the fail-without half of the rule is checked on macOS (OWL-624, "The rule for a variable"). A variable is removed only when the gate is red with it set on Linux.
- **Not in the scripts yet.** Two concurrent gates writing one empty run-cache folder (OWL-624's and OWL-627's "Not checked"): two checkouts of one fixture, the same `origin`, so one folder, two `owlshift gate` at once.
- **Download once.** The two rigs share no layer after `FROM`, so as written they fetch a Rust tool chain and the crates twice; one image with both slices' tool chains halves that. Gradle and Maven are pure Java and could come from the host.
