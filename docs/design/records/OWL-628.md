# OWL-628 · Detect Elixir, Dart, Swift and Deno in owlshift init

Settles: [runtime and operations](../runtime-and-operations.md), "Stack detection (P9)", "More stacks (OWL-624, OWL-627, OWL-628)". The third slice of [OWL-624](OWL-624.md), whose method it keeps: a run cache is written only when the real `owlshift gate`, confined, passed with it and failed with it alone removed; an ecosystem whose lines were not shown to pass confined is a note.

## As built (2026-11-23)

- **Detection.** Four sources join `owlshift_core::stack::detect`, after .NET and before the Makefile: `elixir`, `dart`, `swift`, `deno`, each reading file names only, so `MANIFESTS` and `init::read_root_files` did not change.
- **Elixir** (`mix.exs`): with `mix.lock`, setup `[ ! -f /etc/ssl/cert.pem ] || export HEX_CACERTS_PATH=/etc/ssl/cert.pem; mix local.hex --force --if-missing && mix local.rebar --force --if-missing` (`MIX_INSTALL`) and `mix deps.get --check-locked`, `run_caches.MIX_HOME = "mix"`, `HEX_HOME = "hex"`, and a note on the certificates; designed as two plain `mix local.*` lines, R1 found Mix's download fail confined on macOS without a bundle it can read, and Linux distributions without that file read their certificates from files Mix finds itself (not checked, below). Gate `mix format --check-formatted` with a `.formatter.exs`, then `mix test`. Without the lock, no setup and no run cache; without `.formatter.exs`, no formatting check; a note each. The ticket keyed Elixir on `mix.lock`: the source is `mix.exs`, as Ruby's is `Gemfile`, and a `mix.lock` alone gives nothing.
- **Deno** (`deno.json`, else `deno.jsonc`): with `deno.lock`, setup `deno install --frozen` and gate `deno fmt --check`, `deno lint`, `deno test --frozen --permit-no-files`; without it, no setup, a note, and `deno test --no-lock --permit-no-files`, since a plain `deno test` writes `deno.lock` into the worktree when the settings import a package (checked unconfined), a file the gate refuses to see changed. `--permit-no-files`: a plain `deno test` on a root without tests fails, "No test modules found" (checked unconfined). `run_caches.DENO_DIR = "deno"` either way. The local `deno install` and `--frozen` need Deno 2.
- **Dart and Flutter** (`pubspec.yaml`): a note giving the lines, `dart pub get --enforce-lockfile`, `dart analyze`, `dart test`, or the same with `flutter`, with `run_caches.PUB_CACHE = "pub"`: neither was checked (below).
- **Swift** (`Package.swift`): a note giving `swift package --disable-sandbox resolve`, `swift build --disable-sandbox`, `swift test --disable-sandbox`, saying they were not shown to pass confined and that before OWL-637 `swift build` failed on the user's temporary folder (R1, run before OWL-637 merged). Whether the lines pass since OWL-637 is a later ticket's check.
- **Held by** `stack::tests::an_elixir_root_fetches_its_lock_and_runs_its_tests`, `dart_and_swift_roots_get_a_note_only`, `a_deno_root_installs_its_lock_and_runs_fmt_lint_and_test`, `every_run_cache_detected_passes_the_names_check`, `a_root_holding_several_ecosystems_lists_them_in_the_fixed_order`, and `init::tests::an_elixir_and_deno_root_is_written_and_loads`.

## Live check R1, macOS (2026-11-22 and 23)

Script: [`owl-628.sh`](../live-checks/owl-628.sh), OWL-627's harness: per ecosystem, a fixture repository served on a local bare remote, `owlshift init --tracker markdown --skip-secrets` of this branch, its `owlshift.toml` committed unedited, then `owlshift gate`; then once per `run_caches` line, that line alone removed. `STACK_EDIT` applies a `sed` script to the written file, for the experiments below, which say so; they ran with the `main` binary of the day, which detects none of the four.

macOS 26.6.2, Apple silicon, `sandbox-exec`. Unpacked for the check from their release archives: Deno 2.9.8 into a scratch folder under `/private/tmp`, Elixir 1.20.5 on Erlang/OTP 28 (the Erlang Ecosystem Foundation's macOS build) into `/Users/Shared`, removed afterwards: the sandbox closes the shared `/tmp`, so `/bin/sh` could not read Elixir's scripts there ("Operation not permitted"), where Deno's binary still ran. Used as found: Swift 6.4 of the Command Line Tools, without Xcode. The fixture's lock was made unconfined with `MIX_SEED`, a Mix home holding Hex installed from Hex's archive fetched by `curl`: `mix local.hex` stops at 60 s, and the network took 75 s for its 1.3 MB.

The network of the check ran at 9 to 28 kB/s. The Dart SDK, 238 MB, was queued after Erlang/OTP and had 38 MB of it when the Elixir check ended and was stopped, and the Flutter SDK is larger still: neither was checked, and `init` gives them a note. The final runs of Elixir and Deno used this branch rebased on OWL-637.

It decides: Elixir and Deno are kept, each with the lines above; every variable written passed with it set and failed with it alone removed. Swift is a note, its lines taking `--disable-sandbox`, until a check since OWL-637, whose profile answers the question for the user's temporary folder with nothing, shows them pass. Dart and Flutter are notes.

## Not checked

- Linux, above: every variable written rests on macOS, and the Mix install line, which there finds no `/etc/ssl/cert.pem` on Ubuntu and lets Mix read the system's certificates itself.
- Swift since OWL-637, which merged after R1: its lines may pass on macOS now.
- Swift on Linux, where SwiftPM's own sandbox does not exist and the temporary folder is `TMPDIR`'s: the lines may pass there.
- Dart and Flutter, above.
- An Elixir project whose tests need a service, such as Ecto's database in a Phoenix application: `mix test` fails there as it would in the project's CI without the service. A root without `test/`, and a `.gitignore` without `_build/` and `deps/`, which the gate then names as changed files.
- A root holding both `package.json` and `deno.json`: both sources write their lines.
- Two confined runs writing one of the new folders at once.
